# Signal Ledger

Signal Ledger 相信秩序不是裝飾，而是可信度的可視形式。空間由克制的幾何、清楚的
留白與可追索的節點構成；資訊不靠段落解釋，而由對齊、距離與層次自然顯影。每一道
線與每一個交會都應像研究紀錄般精確，呈現經過無數次校準的專業工藝。

色彩是證據的語言。深墨綠建立可信的底層，薄荷綠代表通過驗證的訊號，粉藍承載觀察，
杏桃只標示需要注意的差異，淡紫則保留給不確定性。所有顏色必須經過 painstaking
attention 反覆平衡，讓對比清楚卻不喧嘩，像由頂尖設計者長時間推敲出的科學儀器。

尺度形成研究節奏：少數大型字形提供方向，微型座標與細線建立 provenance。重複的
圓點、矩形與路徑暗示樣本、Mask 與資料流，但不直接描繪具象物件；熟悉系統的人會在
其中讀到 PCB trace、capsule silhouette 與 probability field，其他人仍能感受完整秩序。

構圖以不對稱平衡創造前進感，主訊號沿固定格線推進，局部偏移則像被定位的 anomaly。
視覺重量必須經過 master-level execution 精準配置，任何元素都不能只是填空；每個
空白與每個密度變化都像出自數十小時的細緻修整。

文字僅作座標，不作說明。作品最終應像一件可被審核的研究器物：冷靜、可讀、帶有人的
判斷痕跡，又具有 painstaking craftsmanship 的完成度。整體必須讓人直覺相信，其背後
存在嚴密方法、完整證據與對負面結果同樣誠實的紀律。
